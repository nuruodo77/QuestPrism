# UX pass — Implementation Plan (v1.8.0)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (inline, per user CLAUDE.md).

**Goal:** Make the QuestPrism panel self-explanatory (sections, consistent polarity and wording, per-type tooltips, distinct trivial icon), give live feedback (hidden counts in status bar and quick menu), and smoother interaction (Escape closes, right-click solo, open beside the map, single close control, wider default).

**Architecture:** Logic first, UI second. `Core/Filter.lua` gains `GetPinType(pin)` (the classifier that `ShouldShowPin` now uses). `Hooks/WorldMap.lua` counts pins it hid per type on each refresh and exposes `GetHiddenCounts()/GetHiddenTotal()` plus one `SetRefreshListener(fn)` for the panel status text. `Core/Settings.lua` gains `Solo(key)/IsSoloed(key)` with an in-memory snapshot; any manual `Set` of a filter key ends solo mode. UI files consume these.

**Spec:** approved suggestion list in chat, 2026-09-05 ("do it all").

## Global Constraints
- Interface 120100, no new libraries. Version → 1.8.0. Both locales updated.
- Wording: the UI says "another character" / "done on another character" everywhere; column header "Hide if done on another character"; no "warband"/"alt"/"account" in user-facing text except the existing account-wide toggle label.
- Hidden counts count only pins QuestPrism itself hid or dimmed (never Blizzard-hidden pins).
- Solo snapshot is session-only (not saved). Right-click on a type's Show checkbox toggles solo.
- Escape closes the panel: global name `QuestPrismPanelFrame`, registered in `UISpecialFrames`.
- Opening from the world-map button anchors the panel to the map: outside its right edge, or inside the top-right when the map is maximized. Opening from elsewhere keeps the saved position.
- AceGUI bottom Close button hidden; status bar stretched to the right edge. Default size 460×600.
